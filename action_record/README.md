# 动作录制（尚未人工验证）

在 滤镜 > 修图工具 里有三步：开始录制、停止录制、播放动作。

录制开着的时候，只有这三个本来就带参数的命令会把自己记下来：一键频率分离、一键加深减淡搭建、选出主体（主体或皮肤，以及当时用的羽化）。手绘、液化笔触和点修复单击不录，因为它们要画布上的一个点。

停止时起个名字。动作写成 JSON，放在当前这个 GIMP 的配置目录 `action-record/actions/` 里，重启还在。播放时先找本版本，再找另一个版本（3.0 和 3.2），所以一边保存的动作另一边通常也能播。

不用录制也可以直接播放内置动作「自然修图准备」：按频率分离自己的默认（半径 0，也就是按长边自动算），再按加深减淡搭建自己的默认（柔光、带观察层、不强制放在最顶）。这两个插件的默认参数没有改。

频率分离记下来的半径是当时真正用掉的像素值，不是「自动」。
每一步会记下当时用的图层（名字，以及它在图层组里的位置，隐藏的图层也算）。播放前先选中那一层再执行。选出主体如果当时点在频率分离或加深减淡生成的图层上，记的是原来的照片图层，不会在灰色的加深减淡层上重跑。找不到那一层就停下，不会改到别的图层。
