# 去油光 / De-shine（尚未人工验证）

菜单：滤镜 > 修图工具 > 去油光 / De-shine

## 怎么用
- **新手模式**：拖「力度」（0–100，默认 50），确定。生成图层「去油光」，蒙版 = 自动找到的油光 × 力度。
- **专业模式**：同样生成「去油光」层；上面再加一层「去油光画笔」（全力度去油光、黑蒙版）。
  插件已选中它的蒙版、前景设为白色、工具设为画笔、不透明度 = 力度。用白色涂 = 去油光，黑色涂 = 擦回。
  「去油光」层的蒙版也能用白/黑画笔改。
- 其他选项：检测灵敏度（越高越能抓淡反光）、边缘柔和度、只处理脸部（默认开，用 YuNet 认脸，避开眼睛和嘴）。
  先画了选区就只处理选区里面。

## 原理
1. 皮肤范围：认脸椭圆 ∩ 肤色，离开脸的轮廓一点（避免把窗边轮廓光当油光）。
2. 油光 = 比周围皮肤亮、而且颜色更淡的地方（在低频上比，局部参考肤色排除亮斑后再算一次）。
3. 只改低频：亮度往周围肤色压（最多降 14 个 L，保留脸的立体感），颜色往周围肤色靠；高频（毛孔、纹理）原样拷回，略加一点对比补回被油光冲淡的纹理。
4. 原图层不改；结果都是新图层 + 蒙版。

## 测试
`gimp-console-3.0 -i --quit --batch-interpreter=python-fu-eval -b "exec(open('de_shine/test_deshine.py').read())"`
（`DESHINE_TEST_IMAGE` 指定测试照片）。只在盒子上的 GIMP 3.0.4 无界面测过；Windows GIMP 3.2.6 和对话框没测过。

## 已知限制
- 侧光很强时，亮的半边脸边缘可能也被当成一点油光，用蒙版擦掉即可。
- 没认到脸且勾了「只处理脸部」会报错，画面不变；可关掉它或先画选区。
