# 去油光 / De-shine（尚未人工验证）

菜单：滤镜 > 修图工具 > 去油光 / De-shine

## 怎么用
- **新手模式**：拖「力度」（0–100，默认 50），确定。生成图层「去油光」，蒙版 = 自动找到的油光 × 力度。
- **专业模式**：同样生成「去油光」层；上面再加一层「去油光画笔」（全力度去油光、黑蒙版）。
  插件已选中它的蒙版、前景设为白色、工具设为画笔、不透明度 = 力度。用白色涂 = 去油光，黑色涂 = 擦回。
  「去油光」层的蒙版也能用白/黑画笔改。
- **闪光灯硬光**（默认关）：针对机顶直闪的大块近白高光（额头、鼻梁、颧骨、下巴）。接近过曝的白斑整块算进来，不因“太亮、没纹理”被排除；灵敏度略调高。整块白斑（含柔边）蒙版接近满值。白斑里纹理已经没了的地方，从附近正常皮肤借一点细纹理（只取毛孔级细节、幅度接近周围皮肤，避免塑料感），借来的纹理在 13 L 压暗上限之后再加。没勾时不借纹理，纹理变化保持在 10% 以内。
- 其他选项：检测灵敏度（越高越能抓淡反光）、边缘柔和度、只处理脸部（默认开，用 YuNet 认脸，避开眼睛和嘴）。
  先画了选区就只处理选区里面。

## 原理
1. 皮肤范围：认脸范围（下半部分按下颌收，不过下巴，脖子不处理）∩ 肤色，离开脸的轮廓一段（避免把侧光轮廓当油光）。
2. 油光 = 比周围皮肤亮、而且颜色更淡的地方（在低频上比，局部参考肤色排除亮斑后再算一次）。
3. 只改低频：亮度往周围肤色压（最终像素最多降 13 个 L，保留脸的立体感），颜色往周围肤色靠；高频（毛孔、纹理）原样拷回，不放大。
   蒙版按最强油光归一，按线性值写入（GIMP 合成用的就是线性值）：力度 25/50/75/100 = 蒙版峰值 64/128/191/255。
4. 原图层不改；结果都是新图层 + 蒙版。

## 已知限制
- 额头、脸颊上很淡的油光不一定抓得到，可调高灵敏度、勾「闪光灯硬光」，或用专业模式的画笔补。
- 嘴巴保护区（上唇附近）里的白点不处理。
- 脸的最外侧一圈和下巴以下不处理（下巴尖上的闪光点只处理一部分）。
- 过曝成纯白的闪光点只能压暗 13 L 以内，压不回正常肤色。
- 没认到脸且勾了「只处理脸部」会报错，画面不变；可关掉它或先画选区。
