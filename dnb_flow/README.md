# 轻柔涂抹 / Gentle D&B Stroke（尚未人工验证）

菜单「滤镜 → 修图工具 → 轻柔涂抹」。过程名 `python-fu-dnb-flow`。

先用「一键加深减淡搭建」做出 50% 灰的柔光层，再选中「加深减淡 D&B」这一层（不要涂在照片上）。这个工具不替换搭建，只在那层灰上走一笔。

对话框跟不了鼠标，也读不到数位板，所以不会假装有笔压。填起点和终点（终点小于 0 就是单独一笔点）。默认偏轻：流量 18，不透明度上限 24，半径 48，边缘全软。

- 流量：这一笔里，重叠的笔点叠多快。
- 不透明度：这一笔的天花板。笔点叠再多，也停在这个上限，不会乘成一个死印。
- 压力：默认 -1，表示没有这一项。只有你自己填 0 到 1，才会拿它去乘流量，不会再和不透明度乘一次。

再运行一次就是第二笔，可以在第一笔上继续叠，每一笔仍有自己的上限。照片像素不被动，所以皮肤纹理还在灰层下面。对话框没有人工点开过。
