# 柔和液化 / Soft Mesh Liquify（尚未人工验证）

菜单位置：滤镜 → 修图工具 → 柔和液化 / Soft Mesh Liquify

在当前图层上做一次柔和的网格变形。边缘用平滑衰减收到 0，不会出硬折痕。GIMP 自带的变形工具手感偏硬，这个插件用自己的位移网格，再交给 GEGL 的 `map-relative` 重采样。不依赖 numpy（Flatpak 里没有）。

一次调用是一笔：

| 模式 | 作用 |
|---|---|
| 推移 push | 沿一条直线把像素推过去。不给终点时，按角度推一笔（0° 向右，90° 向下） |
| 膨胀 bloat | 从圆心把像素向外推，圆心本身不动 |
| 收缩 pinch | 向圆心收 |
| 旋转 twirl | 绕圆心转，可选顺时针 |
| 还原 restore | 把这一笔范围内的变形往回收。强度 100 时，笔刷中心回到原图 |

参数：笔刷半径、强度（0–100，满强度的推移大约是半径的一半）、硬度（默认 0，最柔；调高也仍是平滑收边）、圆心或笔画的起点/终点。坐标是图层像素。`x1` 或 `y1` 小于 0 时，用选区（没有选区就用整层）的中心。

有选区时只动选区里面。整次操作是一步撤销。

第一次使用会在图层堆栈底部放一个隐藏图层组「液化状态 Liquify State」，里面是变形前的原始像素。还原靠它。不要删这个组，删了就回不到最初的画面。之后的每一笔都叠在同一张网格上，并从原图重新采样，不会一次次把画质磨糊。图层如果改了尺寸，这份原图作废，当前画面会变成新的起点。

位移网格存在该图层的附加数据里。笔刷很大时，这份数据会比较大。

认脸（眼睛、下颌那些滑杆）是这个插件计划中的下一步，这一版不做。

对话框这次没有人工点开过。无界面调用过程名是 `python-fu-mesh-liquify`。

## 冻结（尚未人工验证）

冻住的像素完全不动，就算笔刷盖上去也一样。这是在选区限制之外另加的，不是拿来替换选区。

对话框里「冻结」有三种：

- 不冻结。
- 用冻结图层。另建一个图层（可以叫「冻结」），用白色涂要保护的地方，黑色是可以动的。用完这一笔，冻结图层会被隐藏（不删除），免得盖住照片；要改蒙版再把它显示出来。亮度达到一半以上就算冻住。灰度图或彩色图都可以，按亮度读。
- 把当前选区变成冻结。选中的像素冻住。这一笔不再同时用选区来限制范围，否则能画的地方全被冻住了。做完这一笔，选区会原样留着。选区如果还在，并且冻结用的是图层，那么选区照旧只让笔刷改选区里面。

冻住的像素位移是 0。紧挨着冻住区域的可动像素会在一段距离里平滑收到 0，避免交界被撕开。这段距离默认大约是笔刷半径的四分之一（最少 8 像素，最多 80），也可以自己填「冻结边缘柔化」。对话框这次没有人工点开过。

强对比的交界（比如下颌贴着木头）如果正好落在位移变化很快的地方，会整段一起挪，而不是被拉成一条宽过渡。离交界远的皮肤仍按笔刷走，不额外磨皮。这一步尚未人工验证。

## 画布笔触（尚未人工验证）

这个对话框收不到鼠标在照片上的拖动，做不到 Photoshop 那种一边画一边液化。能做的是借 GIMP 自己的画笔：

1. 菜单「滤镜 → 修图工具 → 准备液化笔触」。会在最上面加一张透明图层，名字是「液化笔触」，并把它选中。已经有这张图层的话，就把它显示出来并选中，不另建。
2. 用 GIMP 普通画笔在这张图层上画一条线（要有透明底，不要把图层铺满）。
3. 回到要修的照片图层，打开「柔和液化」。笔触来源选「液化笔触图层」，并把那张图层选上。模式用推移。确定之后，像素顺着这条线推。用完这张笔触图层会被隐藏，不删除；要再画就把它显示出来。

方向不是落笔的先后，也不看线的粗细。默认从左端推向右端；竖线从上端推向下端。要反过来（横线往左推，才能把脸收向内侧），在「柔和液化」里勾上「反向」。不勾则和以前一样。冻结、交界收干净、隐藏的「液化状态」组都还在。膨胀、收缩、旋转、还原仍然用坐标，不吃这张笔触图层。


## 按笔撤销（尚未人工验证）

每一笔液化（包括沿「液化笔触」推的那一笔）都会记下来。要退回上一笔，菜单选「滤镜 → 修图工具 → 撤销上一笔液化」。画面按隐藏的「液化状态」里的原始像素重画，那个组不会被删，也不会被显示出来。全部退完时，照片回到动笔之前，组还在。

「重做上一笔液化」把刚撤掉的那一笔加回来。再画新的一笔，重做列表就清空。最多记住 24 笔，更早的不再能退。

这不是 GIMP 的 Ctrl+Z。这个版本的插件里调不到 GIMP 自己的撤销，所以请用上面两个菜单。还原模式也还是靠那个隐藏组；删掉「液化状态」就撤不回，插件会直接告诉你。冻结图层和笔触图层撤销时不会被重新打开。对话框没有人工点开过。

认脸还没有。

## 按脸调整（尚未人工验证）

菜单「滤镜 → 修图工具 → 按脸调整」。过程名 `python-fu-mesh-liquify-face`。

滑块都是 0 的时候不改像素。一次确定是一笔液化，用「撤销上一笔液化」整笔退回。冻结、交界、笔触图层、反向、按笔撤销都还在。

- 眼睛大小：-20 到 20。正数两眼一起略放大，负数略缩小。
- 下颌：-30 到 30。正数往里收，负数放宽。边缘是软的。
- 鼻宽：-20 到 20。正数收窄，负数放宽。和眼睛、下颌用同一次认出来的点。

自动认脸用 OpenCV 的 YuNet（插件目录里的 `face_detection_yunet_2023mar.onnx`，约 230KB，来自 OpenCV Zoo，Apache-2.0）。点是：两眼、鼻尖、两个嘴角。下颌没有单独的点，是按嘴角和脸框下沿估计的。GIMP 3.2 Flatpak 自己的 Python 没有 cv2，插件会去叫本机的 `python3`（需要装了 OpenCV）。Windows 上 GIMP 自带的 Python 也装不了 OpenCV，用 `install.ps1` 的 `helper-python` 组件装一个独立的；插件先看环境变量 `RETOUCH_HELPER_PYTHON`，再看 GIMP 配置目录里的 `retouch-helper-python.txt`，再找常见位置。找不到脸，或者没有 OpenCV，就提示你，像素不动。

手动画框不是认脸。来源选「手动画框」，填左上角和宽高（至少 20 像素），眼睛、下颌、鼻子按这个矩形的比例摆。对话框没有人工点开过。
