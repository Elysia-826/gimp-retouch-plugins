# 柔和液化 / Soft Mesh Liquify（尚未人工验证）

菜单位置：滤镜 → 修图工具 → 柔和液化 / Soft Mesh Liquify

在当前图层上做一次柔和的网格变形。边缘用平滑衰减收到 0，不会出硬折痕。GIMP 自带的变形工具手感偏硬，这个插件用自己的位移网格，再交给 GEGL 的 `map-relative` 重采样。不依赖 numpy（Flatpak 里没有）。

一次调用是一笔：

| 模式 | 作用 |
|---|---|
| 推移 push | 沿一条直线把像素推过去。不给终点时，按角度推一笔（0° 向右，90° 向下） |
| 膨胀 bloat | 从圆心把像素向外推，圆心本身不动 |
| 收缩 pinch | 向圆心收 |
| 旋转 twirl | 绕圆心转，可选顺时针 |
| 还原 restore | 把这一笔范围内的变形往回收。强度 100 时，笔刷中心回到原图 |

参数：笔刷半径、强度（0–100，满强度的推移大约是半径的一半）、硬度（默认 0，最柔；调高也仍是平滑收边）、圆心或笔画的起点/终点。坐标是图层像素。`x1` 或 `y1` 小于 0 时，用选区（没有选区就用整层）的中心。

有选区时只动选区里面。整次操作是一步撤销。

第一次使用会在图层堆栈底部放一个隐藏图层组「液化状态 Liquify State」，里面是变形前的原始像素。还原靠它。不要删这个组，删了就回不到最初的画面。之后的每一笔都叠在同一张网格上，并从原图重新采样，不会一次次把画质磨糊。图层如果改了尺寸，这份原图作废，当前画面会变成新的起点。

位移网格存在该图层的附加数据里。笔刷很大时，这份数据会比较大。

认脸（眼睛、下颌那些滑杆）是这个插件计划中的下一步，这一版不做。

对话框这次没有人工点开过。无界面调用过程名是 `python-fu-mesh-liquify`。
