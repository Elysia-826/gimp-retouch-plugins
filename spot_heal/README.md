# 点修复 / Spot Heal（尚未人工验证）

菜单「滤镜 → 修图工具 → 点修复」。过程名 `python-fu-spot-heal`。

这个对话框收不到在照片上的单击。在图层坐标里填点的位置和半径（4 到 48）。一次最多三个点（第二、第三点的坐标小于 0 就不用）。三个点算一步撤销。

它调用已经装好的 Resynthesizer「修复选区」，用周围的纹理补这一小块，不是把颜色抹平。细的深色线（头发那种）会在补完之后按原像素贴回去，所以线还在，不会涂成一块。如果点正打在这种细线上，而且下面没有更大的一块斑，就直接停，像素不动。

竖线从左右取样，横线从上下取样，免得把线的纹理抽进斑里。取样宽度大约是半径的 1.6 倍（12 到 36 像素）。

需要本机有 Resynthesizer（`plug-in-heal-selection`）。GIMP 3.0 是自己编译的，3.2 是 Flatpak 扩展，两边都能调用。对话框没有人工点开过。
